## Features

**Personal Purple Estimate:** A small, movable overlay projects your personal purple chance on raid completion. Enabled by default; toggle it in Loot settings. It uses observed damage and deaths, with equal shares assumed for rooms not yet observed. Ocellus phases are normalized individually using assumed weights of 85.71 / 42.86 / 85.71 / 85.71 points. These weights are not official Jagex rates. It is an estimate, not the server's roll: minion soft caps, assumed Ocellus phase weights (P1:P2:P3:P4 = 2:1:2:2), missed hits, and changing team sizes affect accuracy. Joining mid-raid shows incomplete tracking instead of a percentage.

Rates follow the [3 November loot mechanics post](https://secure.runescape.com/m=news/quest-month-kick-off-tfa-tweaks--more?oldschool=1) and may change with the announced balancing update.
